# Section Library — Available Patterns

Each section is a function call. Pick 8-12 sections per page. NO TWO PAGES should use the same sequence.

## HERO sections (pick 1)
- `hero_cover` — full-bleed image with dark overlay, centered headline + subline + CTA button
- `hero_split` — grid: text left (headline + intro + button), image right
- `hero_offset` — background image with a floating white card containing headline + intro
- `hero_text` — no image, just oversized centered typography with eyebrow text above
- `hero_stack` — eyebrow label + large headline + lead paragraph, centered

## INTRO sections (pick 0-1)
- `intro_center` — centered max-width paragraph block
- `intro_lead` — oversized first paragraph (1.25rem), left-aligned
- `intro_cols` — two-column grid: main text left, supplementary right
- `intro_stat` — text left with a large single stat number on the right

## CONTENT sections (use for each content section, vary the type)
- `content_prose` — simple readable column (720px max)
- `content_media_left` — image left (45%), text right
- `content_media_right` — image right (45%), text left
- `content_wide_img` — heading + text, then full-width rounded image below
- `content_indent` — left-bordered emphasis block (ember accent)
- `content_steps` — numbered step list with circled numbers
- `content_icon_list` — arrow-prefixed feature list
- `content_timeline` — vertical timeline with dots

## CARD sections (pick 0-2)
- `cards_3` — three-column feature cards with borders
- `cards_2` — two-column feature cards
- `cards_accent` — cards with ember top border
- `cards_dark` — dark background cards (use in ink band)
- `cards_horizontal` — icon left, text right per card
- `cards_stack` — vertical stack of compact cards (narrow)
- `cards_number` — stat cards with large number + label (ONLY for actual numbers like "30°F", "R-8", "15 yrs")

## TABLE sections (pick 0-1)
- `table_standard` — dark header, hover rows
- `table_striped` — alternating row colors
- `table_compact` — tighter spacing, smaller text
- `table_clean` — borderless, subtle border only

## QUOTE sections (pick 0-2)
- `quote_large` — oversized display font pullquote
- `quote_accent` — left ember border + display text
- `quote_card` — quote inside a elevated card
- `quote_center` — centered italic style
- `quote_mark` — large opening quotation mark decoration

## CTA sections (pick 1-2)
- `cta_center` — centered heading + text + button (use in sand band)
- `cta_split` — heading left, button right (inline)
- `cta_card` — elevated card with shadow
- `cta_inline` — compact mid-page prompt (sand bg, italic text + link)
- `cta_urgent` — bordered box, centered

## FAQ sections (pick 1 style)
- `faq_accordion` — clean expandable details
- `faq_bordered` — flat bordered accordion (no cards)
- `faq_cards` — each Q in its own shadowed card
- `faq_numbered` — numbered counter badges

## DIAGNOSTIC sections (pick 0-1)
- `diagnostic_card` — top-accented card with warning items
- `diagnostic_checklist` — checkmark-prefixed list
- `diagnostic_warning` — red-bordered warning box
- `diagnostic_success` — green-bordered solution box

## LIST sections (pick 0-2)
- `list_pills` — horizontal flex-wrap pill tags (sand bg)
- `list_pills_ember` — ember-colored pills
- `list_pills_outline` — outline-only pills

## BAND COLORS (wrap any section)
- `sand` — warm tan background
- `ink` — dark with light text
- `ember` — brand orange with white text  
- `white` — clean white
- `gradient` — dark gradient
- (no band) — transparent/paper background

## SEPARATOR (between sections)
- `sep_gradient` — fading horizontal line
- `sep_wide` — full-width thin line
- `sep_dot` — three dots centered

## RULES
1. Each page must use DIFFERENT section types for its content blocks (don't repeat content_prose 5x)
2. Alternate band colors — never two consecutive same-color bands
3. Place mid-page CTA after section 2 or 3
4. FAQ should use ONE consistent style per page
5. Use at most 1 table per page
6. Use at most 2 quote sections per page
7. Diagnostic/checklist should appear in the first third of the page
8. Final CTA should be in a sand or ink band
